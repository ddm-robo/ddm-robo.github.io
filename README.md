# DDM project page

Static project page for **DDM: Dense Dynamics World Action Modeling for Physics-Sensitive Robotic Manipulation**.

Anonymous submission. The page includes the paper, method illustrations, six simulation replay videos, interactive prediction comparisons, and full result tables.

## Hosting

GitHub Pages publishes the root of the `main` branch. `.nojekyll` enables direct static serving. All asset links are relative so project-path hosting works without a build step.

## Editing

- `index.html`: page content
- `static/css/research.css`: research-page presentation
- `static/js/`: interactive comparisons, video controls, and tables
- `static/`: packaged media and data

Keep recorded simulation pixels, metric units, and source-linked measurements intact when updating examples.
